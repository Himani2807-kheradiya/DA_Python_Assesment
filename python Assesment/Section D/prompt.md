Create a beginner-friendly Python program for a food delivery bill calculator.

Requirements:

1. Accept a list of food items and their prices for a delivery order and calculate the itemised subtotal.
2. Add an 18% GST charge and a flat delivery fee of Rs 30 to produce the final bill amount.
3. Apply a 10% loyalty discount on the subtotal if the customer has placed more than 5 previous orders. Take the number of previous orders as user input.
4. Print a formatted receipt showing each food item, price, subtotal, GST, delivery fee, discount if applicable, and final amount payable.
5. Handle invalid inputs such as negative prices or non-numeric order counts.
6. Keep the Python code simple and beginner-friendly.
